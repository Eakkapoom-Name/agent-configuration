# Why Verification Matters

Versioned tools, prices, APIs, and configuration change. A confident but stale answer can send someone to the wrong command or setup. Verification is a short, targeted check that prevents that failure.

## Respond to common objections

| Objection | Response |
| --- | --- |
| "I do not need sources." | Omit citations if appropriate, but still verify the claim. |
| "This is established." | Current versions and tooling change. Check the live source. |
| "I said I think." | A hedge can still be read as advice. State uncertainty plainly or verify. |
| "There is no time." | A brief check costs less than repairing a wrong command or configuration. |
| "They probably mean X." | Ask when intent matters. Do not substitute a guess. |
| "You cannot verify it now." | Say so clearly and do not present the guess as fact. |
